WEATHER DATA MANAGEMENT SYSTEM
GCC 7.5.0 + C++17 + nlohmann-json 2.1.1

1. VERIFY COMPILER
------------------
g++ --version

Expected target:
g++ (GCC) 7.5.0

2. VERIFY JSON HEADER
---------------------
Make sure your PuTTY/server has:
nlohmann/json.hpp
version 2.1.1

3. SET API KEY
--------------
Do not put the key in APIManager.cpp.

Linux/PuTTY:
export WEATHER_API_KEY="YOUR_REAL_WEATHERAPI_KEY"

Check only whether it is set:
if [ -n "$WEATHER_API_KEY" ]; then echo "API key is set"; else echo "API key is NOT set"; fi

4. COMPILE
----------
g++ -std=c++17 -pthread *.cpp -o weather -lcurl

5. RUN
------
./weather

6. LOGIN TEST
-------------
Start:
1. Login
2. Register
0. Exit

Register:
- Enter username
- Enter password
- Confirm that users.csv is updated
- Confirm that the program returns to Login/Register

Login:
- Enter the registered username/password
- Correct credentials -> Main Menu
- Wrong credentials -> Login/Register menu

7. LOCATION SEARCH TEST
-----------------------
Main Menu -> 1
Enter a city or town search, e.g.:
ch

Expected:
- Location results
- City name
- Region/state
- Country
- Latitude
- Longitude

8. MAIN FUNCTIONALITY TEST
--------------------------
Test each main-menu item from 1 through 17.
Do not use Clear Storage until all storage tests are complete.

9. WEATHER INTELLIGENCE
-----------------------
Main Menu -> 16

Test:
1. Forecast + Current Details + Alerts + Insights
2. API Performance Monitoring
3. API Retry Test
4. Automatic Weather Refresh
0. Back To Main Menu

10. EXIT
--------
Main Menu -> 17
The program must terminate.

11. GCC 7.5 COMPATIBILITY
-------------------------
The source uses C++17 features supported by GCC 7.5.
It does not require C++20.
It does not use std::filesystem.
JSON access is written using APIs compatible with nlohmann-json 2.1.1:
find(), get<T>(), is_object(), is_array(), at(), and operator[].
