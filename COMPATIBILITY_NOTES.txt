WEATHER DATA MANAGEMENT SYSTEM
G++ 7.5.0 + nlohmann-json 2.1.1 compatibility version

BUILD
-----
g++ --version

Compile all source files:

g++ -std=c++17 -pthread *.cpp -o weather -lcurl

If your system reports a filesystem linker error, this project does not use
std::filesystem, so no -lstdc++fs should be required.

API KEY
-------
The source does not contain a hard-coded WeatherAPI key.
Set the key in the same terminal before running:

export WEATHER_API_KEY="YOUR_REAL_WEATHERAPI_KEY"

Check without printing the secret:

if [ -n "$WEATHER_API_KEY" ]; then echo "API key is set"; else echo "API key is NOT set"; fi

Run:

./weather

JSON COMPATIBILITY
------------------
The source avoids newer nlohmann-json APIs such as contains() and value().
JSON field access uses find(), get<T>(), is_object(), is_array(), and
operator[] so it is compatible with the installed nlohmann-json 2.1.1 API.

C++ COMPATIBILITY
-----------------
The project is written for C++17 features available in GCC 7.5.0.
No C++20-only features such as std::format, std::erase_if, ranges, or
container::contains are used.

THREADING
---------
Automatic Weather Refresh uses std::thread and mutex protection. Compile
with -pthread on the Linux/PuTTY environment.

LOGIN FLOW
----------
1. Login
2. Register
0. Exit

Register stores username/password in users.csv and returns to the
Login/Register menu. Login checks users.csv; failed login returns to the
Login/Register menu; successful login enters the main functionality.


FINAL SOURCE FIXES
------------------
- APIManager.cpp reads WEATHER_API_KEY from the environment; no API key is embedded.
- APIManager.cpp includes curl before APIManager.h to avoid Windows byte/std::byte
  namespace conflicts when the same source is also built on UCRT64.
- main.cpp exits on menu choice 17.
- Location search has CURL/HTTP error diagnostics.
- JSON access avoids newer APIs such as contains() and value().
- Weather enhancement JSON access uses operator[], find(), get<T>(),
  is_object(), and is_array() for compatibility with old nlohmann-json releases.
